## 项目简介

这是一个使用 Python 实现的简单 TCP 协议通信项目。

## 我完成的内容

- 阅读并理解协议要求
- 实现服务端基础功能

## 运行方式

### 1. 创建并激活虚拟环境

请先创建并激活 `.venv`。

### 2. 安装依赖

安装 `requirements.txt` 中的依赖。

### 3. 启动服务端

运行 `python server.py`。

### 4. 运行测试或客户端

根据题目要求运行测试，或使用客户端进行验证。
