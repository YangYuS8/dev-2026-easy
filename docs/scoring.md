# 评分细则（面向 agent）

总分 100 分。

## 评分原则

1. 这道题面向初学者，不按高级网络编程标准打分。
2. 优先看协议理解、程序可运行性和核心交互是否完成。
3. 只要逻辑基本正确，就不要因为代码不够优雅而给过低分。
4. 如果 README 能清楚说明实现思路，可以适当正向考虑。

## 一、环境配置与程序可运行性，20 分
- 能正确安装依赖，10 分
- 程序可以正常启动，10 分

## 二、协议理解与实现，30 分
- 能基本按题目协议处理请求，15 分
- 返回内容基本符合要求，15 分

## 三、服务端与客户端通信能力，20 分
- 能建立 TCP 通信，10 分
- 能完成基础收发逻辑，10 分

## 四、测试与结果正确性，20 分
- 核心测试可通过，10 分
- 功能结果基本正确，10 分

## 五、代码质量与 README，10 分
- 代码结构基本清楚，5 分
- README 说明清楚，5 分
